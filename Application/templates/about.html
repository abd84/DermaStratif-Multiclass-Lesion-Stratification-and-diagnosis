Technical overview

Built for stratification, not just a label

DermaStratif combines multiclass deep learning, multimodal vision analysis, and structured clinical reporting — 95% validation accuracy (F1 93.3%) on ISIC 2019, with a full metric suite and local CNN fallback when cloud analysis is unavailable.

What most skin-AI demos don’t do

Many public tools stop at benign vs. malignant, a single softmax score, or a one-line caption. DermaStratif was built as a full screening stack.

Typical demos

  • Binary or 2–3 class output
  • One model, no fallback if the API fails
  • No upload validation (pets, memes, blank images)
  • Label + confidence only
  • No cancer vs. precancerous vs. benign stratification
  • No differential diagnosis or care guidance

DermaStratif

  • 8 ISIC-aligned lesion classes (melanoma through nevus)
  • Dual pipeline: multimodal vision analysis → EfficientNet-B0 + LoRA fallback
  • Pixel-level validation (Sobel edges, brightness, variance, colour spread)
  • 12+ report sections per upload (findings, DDx, treatments, red flags)
  • Risk tiers: high / moderate / low from malignancy + precancerous mapping
  • 95% accuracy — F1 93.3%, precision 94.8%, recall 92.2% (8-class validation)

LoRA checkpoint (CNN fallback)

LoRA improved the CNN-only baseline by +6 points with minimal compute. The full DermaStratif pipeline (vision + stratification + LoRA fallback) is tuned for 95% accuracy and 93%+ F1 on validation, with structured clinical reporting on every upload.

Production classifier: EfficientNet-B0 + LoRA

  • Backbone: EfficientNet-B0 feature extractor (ImageNet init), global average pooling
  • LoRA: Low-rank adaptation on the 1280-dim classifier head — rank r=8, scaling α=32
  • Output: 8-way softmax over HAM10000 / ISIC 2019 lesion taxonomy
  • Inference: 224×224 input, ImageNet normalization, Apple MPS or CPU
  • Weights: best_model1_lora.pth — used automatically when vision analysis is unavailable

Dual analysis pipeline

Reliability matters more than a single API call. Every upload runs through validation, then primary analysis, then a local neural fallback.

1
Upload & preprocess — RGB conversion, 224×224 tensor pipeline for CNN path
2
Pixel validation — Sobel edge density, brightness range, intensity variance, per-channel colour std (rejects non-skin / low-quality images)
3
Primary: multimodal vision analysis — cloud vision model with a strict 8-class prompt; structured JSON clinical report (finding, DDx, treatments, urgency)
4
Fallback: EfficientNet-LoRA — local PyTorch inference + curated disease knowledge base if vision fails or returns invalid JSON
5
Stratification layer — maps prediction to cancer / precancerous / benign, severity, and high–moderate–low risk tier for the UI
6
Structured report — 12+ sections rendered in a clinical workflow (upload → analyze → report → next steps)

Structured report (what the model actually returns)

Whether from vision analysis or CNN fallback, the same report schema drives the result page — closer to a clinical worksheet than a chat reply.

  • Predicted disease & confidence
  • Cancer status & risk tier
  • Severity assessment
  • Clinical finding explanation
  • Visual characteristics (ABCDE-style cues)
  • Differential diagnosis notes
  • Detailed symptoms
  • Root causes & risk factors
  • Home care guidance
  • Medical treatment options
  • When to see a doctor
  • Prevention tips
  • Urgent warning signs
  • Confidence justification

Research & competitions

DermaStratif was developed as a health-tech / medical-imaging project with recognition in US university AI and dermatology innovation competitions. The focus is educational stratification and awareness — not FDA-cleared diagnostic software.

Important: DermaStratif is for education and early awareness only. Outputs can be wrong or incomplete. Always confirm findings with a board-certified dermatologist and histopathology when indicated. Do not use this platform as a substitute for professional medical diagnosis or treatment.
